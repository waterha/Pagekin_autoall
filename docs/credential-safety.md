# 防止个人凭据进入 GitHub

API Key、访问令牌、密码、私钥和个人模型配置只保存在本机，不提交、不推送。应用设置目录位于仓库之外。

本仓库提供本地检查，不上传待检查内容，也不输出密钥原文：

```sh
git config --local core.hooksPath .githooks
node scripts/check-secrets.mjs --tracked
node scripts/check-secrets.mjs --history
```

启用后，提交前检查暂存区，推送前检查将要发送的历史对象。发现疑似凭据或检查未完成时会阻止操作；不要使用 `--no-verify` 绕过检查。新克隆的仓库需要单独启用本地 hooks。

检查包含常见凭据格式、私有配置文件路径，以及本机书童模型配置中的实际凭据匹配。测试数据仅对已核实的文件及值哈希作精确例外，不会跳过整个测试目录。本机配置中的实际凭据不适用这些例外。

检查是额外防线，不能识别所有格式或图片中的信息。提交仍应只选择代码和必要文档，不加入日志、运行数据库、截图、配置导出和构建产物。若发现真实凭据已进入历史，先停止推送；联系凭据提供方撤销或更换，再协调清理远端历史，不能只删除当前文件。
